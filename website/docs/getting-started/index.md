## Nullus 가 하는 일

DevOps 엔지니어가 **검증된 CI/CD 도구 조합을 고르고**, 웹 UI 에서 **노코드로
설정한 뒤**, 버튼 한 번으로 **Kubernetes 클러스터에 전체 DevSecOps 스택을 자동
설치**하게 하는 플랫폼입니다.

"클러스터 준비 → 스택 선택·설치 → 배포 관측" 을 하나의 흐름으로 묶는 데
집중합니다. 플랫폼 팀은 표준 템플릿과 버전 호환성 정책을 운영하고, 개발 팀은
반복적인 인프라 구성 없이 검증된 파이프라인을 바로 씁니다.

## 두 가지 길

| | 짧은 길 | 전 과정 |
|---|---------|---------|
| 무엇 | 플랫폼(API + 웹)만 띄우기 | kind 클러스터부터 백업·복구까지 |
| 시간 | 몇 분 | 한 시간 남짓 |
| 필요한 것 | Docker Compose | 여기에 kind·kubectl·helm |
| 문서 | [로컬에서 띄우기](run-local.md) | [E2E 가이드](e2e.md) |

## 구현 범위를 먼저 알아 두세요

!!! warning "GitLab 중심으로 구현돼 있습니다"
    스택 자동화는 GitLab 기반 흐름이 기준입니다. GitHub 호환은 다음 단계
    과제이고, CI/CD 영역은 안정화를 계속 진행하고 있습니다.

!!! warning "기본 인증 모드는 운영에 쓸 수 없습니다"
    설정하지 않으면 인증 모드가 `session` 인데, 이 모드는 **서버가 요청 헤더의
    역할 주장을 그대로 믿습니다.** 개발용입니다. 운영에서는 `oidc` 로 바꿔야
    합니다 — [관리 개요](../features/admin/index.md#인증-모드를-먼저-확인하세요)에
    적어 두었습니다.

각 화면에서 아직 동작하지 않는 기능은 해당 문서에 그대로 표시해 두었습니다.
[기능 한눈에 보기](../features/index.md)에서 전체 목록을 보세요.
