# 처음부터 끝까지 (E2E)

빈 리눅스·macOS 노트북에서 시작해, **kind 클러스터를 띄우고 → 스택을 설치하고 →
파이프라인을 돌리고 → 백업하고 → 지우고 → 복구해서 → 파이프라인을 이어 가는**
전 과정을 한 번에 따라가는 가이드입니다.

[**로컬 E2E 가이드 열기 →**<span>15단계 + 부록 3장. 왼쪽 레일에서 진행한 단계를 체크하며 따라갈 수 있습니다.</span>](../guides/local-e2e.html)

</div>

## 가이드가 다루는 범위

| | 단계 | 내용 |
|---|------|------|
| **준비** | 1 | 준비물 — 필요한 도구와 최소 사양 |
| | 2 | 플랫폼 띄우기 |
| | 3 | 로그인·클러스터 확인 |
| **스택** | 4 | GitLab + Argo CD + SonarQube 스택 설치 |
| | 5 | 도구 열기 — 8개 도구에 도메인으로 접속 |
| | 6 | API 연결 설정 — GitLab 주소와 백업 |
| **CI/CD** | 7 | CI/CD 템플릿 고르기 |
| | 8 | 파이프라인 만들고 실행 |
| | 9 | 결과 확인·지문 기록 |
| **백업·복구** | 10 | 백업 |
| | 11 | 삭제 |
| | 12 | 복구 |
| | 13 | 복구 후 배선 |
| **이어서** | 14 | 파이프라인 이어 가기 |
| | 15 | 정리 |
| **부록** | — | 문제 해결 · SonarQube 쓰기 · 알려진 제약 |

## 이 가이드는 실제로 돌려 본 결과입니다

가이드에 적힌 명령과 기대값은 추정이 아니라 **처음부터 끝까지 실제로 실행해
확인한 것**입니다. 가장 최근 검증에서 측정한 값은 이렇습니다.

| 항목 | 측정값 |
|------|--------|
| 플랫폼 기동 | 68초 · 스모크 16/16 |
| 스택 설치 완료 | 740초 · 파드 39개 · 비정상 0 |
| 도구 접속 | 8개 전부 응답 |
| 백업 | 76초 · 1,069,537,942 바이트 · 정합성 검사 11건 통과 |
| 네임스페이스 삭제 | 86초 (수동 개입 없음) |
| 복구 | 71초 · PVC 6/6 |
| 파이프라인 재실행 | 4개 작업 전부 성공 · 품질 게이트 통과 |
| 정리 | 15초 — 클러스터·컨테이너·볼륨 0 |

!!! tip "따라가기 전에"
    가이드 2단계가 `sudo` 를 한 번 씁니다 — 도구에 포트 없이 도메인으로 접속하려면
    호스트의 `/etc/hosts` 와 CoreDNS 양쪽에 항목을 넣어야 하기 때문입니다.
    `./scripts/setup-local-domain.sh --apply-hosts` 가 그 일을 합니다. 이 옵션을
    빼면 3단계 로그인이 되지 않습니다.

!!! warning "지우는 단계가 들어 있습니다"
    11단계는 네임스페이스를 **실제로 삭제**하고, 15단계는 kind 클러스터와 도커
    볼륨까지 지웁니다. 쓰던 클러스터가 있는 기계에서는 15단계를 건너뛰거나
    명령을 먼저 읽어 보세요.

## 더 짧은 길

전 과정이 아니라 플랫폼만 띄워 보고 싶다면 [로컬에서 띄우기](run-local.md)가
짧습니다. 준비물만 먼저 확인하려면 [준비물](prerequisites.md)을 보세요.
