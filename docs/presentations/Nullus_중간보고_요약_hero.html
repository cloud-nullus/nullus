04 · 내부 엔진설치 순서 해석

순서는, 엔진이 푼다.

“GitLab 설치” 한 줄에 실제로 필요한 선행 조건

GitLab→PostgreSQL 기동 필요
PostgreSQL→비밀번호 Secret 필요
Secret→ESO 의 저장소 복제 필요
ESO→시크릿 저장소 unseal 필요
시크릿 저장소→PVC Bound 필요
PVC→StorageClass 존재 필요
한 칸 내려갈 때마다 선행 조건이 하나씩 늘어난다
입력
스텝은 선행 조건만 선언
29개 스텝이 각자 “무엇이 먼저 있어야 하는가”만 선언
출력
순서는 엔진이 산출
의존 그래프를 풀어 실행 순서 산출 · 정의와 실행 순서의 일치를 코드가 강제
사람이 29단계를 기억하는 대신 엔진이 매번 다시 산출 — Harbor 를 고르면 Nexus 스텝이 빠지고 후속 의존까지 반영
