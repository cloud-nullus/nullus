## 1. 요약

- **Phase 1 의 기능 축(F0~F10)은 모두 구현됐다.** 일부는 계획을 넘어섰다 —
  Golden Path 템플릿은 Phase 3 목표 3개 대비 **6개**, 호환성 매트릭스는 **5개**다.
- **계획에 없던 축이 늘었다.** 외부 SCM(GitHub) 지원, 스택별 OpenBao 시크릿 평면,
  토큰 회전 관리가 4월 이후 들어왔다.
- **문서와 구현의 괴리가 컸다.** 8월 초 기준 API 설계 문서는 엔드포인트 27개를
  기술했는데 실제는 108개였고, DB 스키마 문서는 마이그레이션 `000013` 까지였는데
  실제는 `000061` 이었다. 이번 점검에서 A·B 그룹 문서를 현행화했다(PR #129, #130).
- **손대야 할 불일치 3건을 찾았다**(6장). 모두 동작에 즉시 문제가 되지는 않지만,
  화면이 만들어졌는데 도달할 수 없거나 API 만 있고 화면이 끊긴 상태다.

## 6. 이번 점검에서 발견한 불일치

동작이 즉시 깨지지는 않지만 방치하면 혼란을 키우는 항목들이다. **문서로 고칠 수 없고
제품·코드 판단이 필요해 여기 기록만 남긴다.**

### 6.1 도달할 수 없는 화면 4개

`cicd-golden-path-page`, `cicd-pipeline-setup-page`, `stack-deployment-logs-page`,
`token-management-page` 가 컴포넌트로 존재하지만 라우트에도 사이드바에도 없고,
전체 소스 어디에서도 import 되지 않는다.

특히 `token-management-page` 는 백엔드에 토큰 소스 API 가 **9개**
(`/admin/token-sources` 조회, `:id/rotate`, `/approve`, `/pause`, `/resume`,
`/re-auth`, `/reveal`, `:id/events`) 있는데 화면만 끊겨 있다. 회전 실패나 승인 대기
상태를 UI 로 볼 방법이 없다.

**판단 필요**: 메뉴에 연결할지, 미완성이면 지울지.

### 6.2 Developer 랜딩과 메뉴 노출 불일치

`home-page.tsx` 의 `getRoleLandingPath` 가 Developer 를 `/cicd/templates` 로 보내는데,
사이드바는 그 메뉴를 Developer 에게 숨긴다(`roles: ['admin','devops']`).
라우트는 `['admin','devops','developer']` 를 허용하므로 홈에서 들어가는 것은 되지만,
**한 번 벗어나면 메뉴로 다시 찾아갈 수 없다.**

**판단 필요**: 사이드바에 노출할지, 랜딩을 `/cicd/list` 로 바꿀지.

### 6.3 등록되지 않은 라우트 핸들러

`PipelineHandler.RegisterStackRoutes`(`GET /api/v1/stacks/:stackId/pipelines`)가
정의돼 있으나 `main.go` 에서 호출되지 않아 서비스되지 않는다. 스택별 파이프라인 조회는
`GET /api/v1/cicd/pipelines?stack_id=` 로 대체돼 있고 프론트도 그쪽을 쓰므로 동작에는
문제가 없다.

**판단 필요**: 죽은 코드로 제거할지.

## 8. 운영상 알아둘 제약

로컬·검증 환경에서 반복해서 부딪힌 것들이다.

- **한 클러스터에 스택은 하나만 설치할 수 있다.** OpenBao 의 cluster-scoped
  ClusterRoleBinding(`openbao-server-binding`)을 먼저 설치한 스택이 소유하고, 살아 있는
  릴리스는 인수하지 않는 규칙 때문에 두 번째 설치가 반드시 실패한다. 의도된 차단이다.
- **시크릿 평면은 항상 설치된다.** `authentication.provider` 선택과 무관하다 —
  PostgreSQL·MinIO 가 `provisioning_secrets` 가 만든 Secret 을 참조하기 때문이다.
- **GitHub 스택의 워크플로는 OpenBao 에 접근하지 않는다.** 내장 `GITHUB_TOKEN` 으로
  이미지 push 와 매니페스트 되쓰기를 처리하고, 조직 PAT 는 플랫폼 쪽에서만 쓴다.
